# Meiyi Lau — Portfolio

UI/UX, graphic design, editorial work, photography, and personal projects.

## Website

https://stepauntmei.github.io/Portfolio/

## Structure

- `index.html`: postcard homepage
- `work/`: selected work and project pages
- `about/`, `contact/`, `interests/`: personal pages
- `assets/`: optimized images, fonts, and video
- `style.css`, `app.js`: shared styling and interactions

This is a static site with no build step. GitHub Pages serves the `main` branch from the repository root. Local links use `/Portfolio/`, matching the project URL.

## Local preview

From the parent folder, run `python3 -m http.server 8000`, then open `http://localhost:8000/Portfolio/`.

All artwork and personal images remain the property of their respective creators. Original publication credits are retained.
